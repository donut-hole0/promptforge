HOW IT WORKS

Three steps from endpoint to verdict.

01 / TARGET

Point it anywhere

Aim PromptForge at any OpenAI-compatible endpoint, agent, or chatbot wrapper. No SDK, no instrumentation.

02 / FORGE

Fire the battery

ATTACK TAXONOMY

Five vectors. One hundred-plus payloads.

VECTOR 01

Direct injection

Override the system prompt head-on — "ignore previous instructions" and its many descendants.

VECTOR 02

Jailbreak

Role-play, personas, and DAN-style coercion that talk the model out of its guardrails.

VECTOR 03

Prompt extraction

Coax the model into disclosing its own hidden system prompt and configuration.

VECTOR 04

Indirect injection

Smuggle instructions through context, fake system messages, and authority impersonation.

VECTOR 05

Obfuscation

Base64, encoding tricks, and hidden instructions that slip past naive filters.
